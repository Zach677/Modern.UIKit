# Contributing to Modern.UIKit

Modern.UIKit is a personal project that I maintain in my free time. Bug
reports and small, focused pull requests are welcome. To work on the template
itself, read ["Developing Modern.UIKit"](HACKING.md).

## The Critical Rule

**You must understand your code.** If you cannot explain what your change does
and how it interacts with the rest of the template without the aid of AI
tools, do not contribute to this project.

You can use AI tools to write code, and you must say that you did. Read the
[AI Usage Policy](AI_POLICY.md).

## Report a bug

1. Search the open and closed
   [issues](https://github.com/Zach677/Modern.UIKit/issues?q=is%3Aissue) first.
2. If the bug is not there, open an issue. Include the steps to reproduce the
   problem, what you expected, what happened, and your Xcode and macOS
   versions.

Modern.UIKit creates new apps only. It does not migrate existing repositories.

## Suggest a feature or ask a question

Open an issue and describe the problem that you want to solve. A clear problem
is more useful than a finished design.

## Open a pull request

- For a small fix, open a pull request directly.
- For a larger change, open an issue first, so that we agree on the direction
  before you write the code.
- Keep one topic in one pull request.
- Run the checks in [HACKING.md](HACKING.md#checks) before you open the pull
  request.
