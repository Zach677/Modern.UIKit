# Developing Modern.UIKit

This document describes the technical details behind Modern.UIKit's
development. If you'd like to open any pull requests or would like to implement
new features into Modern.UIKit, please make sure to read our
["Contributing to Modern.UIKit"](CONTRIBUTING.md) document first.

Modern.UIKit's detailed development guide is intentionally small for now.
Use the current project docs as the source of truth:

- [README.md](README.md) for the starter overview and usage flow.
- [AGENTS.md](AGENTS.md) for repository working rules.
- [skills/uikit-starter/SKILL.md](skills/uikit-starter/SKILL.md) for the
  agent-facing workflow contract.

This file is reserved for future local development, build, test, debugging,
and release details that should not live in the contribution process document.
